# HTML & CSS Basics

This repository contains daily practice files (`day1.html` to `day7.html` + `styles.css`) that progressively build your web development foundation. Each day introduces new concepts with practical examples.

---

## 📅 Day 1 – HTML Basics
- Structure of an HTML document (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`).
- Text elements: paragraphs, headings (`<h1>`–`<h6>`).
- Tables (`<table>`, `<tr>`, `<th>`, `<td>`).
- Text formatting: `<b>`, `<i>`, `<u>`, `<s>`, `<code>`, `<mark>`, `<sub>`, `<sup>`.
- Deprecated tags included for learning: `<center>`, `<marquee>`, `<strike>`, `<big>`.

---

## 📅 Day 2 – Lists, Links, Images, Multimedia
- Lists:
  - Ordered (`<ol>`), unordered (`<ul>`), nested lists.
- Links:
  - `<a href="...">` with `target="_blank"`.
- Images:
  - `<img src="..." alt="...">`.
  - Image as a link (`<a><img></a>`).
- Multimedia:
  - Audio (`<audio controls><source></audio>`).
  - Video (`<video controls><source></video>`).
  - Embedded content (`<iframe>` for YouTube).

---

## 📅 Day 3 – Forms & Inputs
- Form basics: `<form action="" method="">`.
- Input types: text, email, password.
- Radio buttons & checkboxes.
- Dropdowns (`<select><option>`).
- Textarea (`<textarea>`).
- Buttons: submit & reset.

---

## 📅 Day 4 – CSS Selectors, Colors, Fonts, CSS Types
- Selectors:
  - ID (`#id`), class (`.class`), element (`p`), grouping (`div, p`).
- Colors: named colors, hex, RGB.
- Fonts: serif, sans-serif, monospace.
- CSS application methods:
  - Inline CSS (`style=""`).
  - Internal CSS (`<style>` in `<head>`).
  - External CSS (`styles.css` linked via `<link>`).

---

## 📅 Day 5 – Box Model, Flexbox, Grid
- **Box Model**:
  - Content, padding, border, margin.
  - `box-sizing: content-box` vs `border-box`.
- **Flexbox**:
  - `display: flex`, `flex-direction`, `justify-content`, `align-items`.
  - Item properties: `flex-grow`, `flex-shrink`, `order`.
- **Grid**:
  - `display: grid`, `grid-template-columns`, `grid-template-rows`, `gap`.
  - Item placement: `grid-column`, `grid-row`.

---

## 📅 Day 6 – Advanced CSS
- Positioning: static, relative, absolute, fixed, sticky.
- Z-index: stacking order.
- Display: block, inline, inline-block.
- Overflow: visible, hidden, scroll, auto.
- Pseudo-classes: `:hover`, `:active`, `:focus`, `:nth-child`.
- Pseudo-elements: `::before`, `::after`.
- Transitions: smooth hover effects.
- Responsive design basics: media queries, relative units (`em`, `rem`, `%`, `vh`, `vw`).

---

## 📅 Day 7 – Semantic HTML, Advanced Forms, CSS Variables, Accessibility
- Semantic tags: `<header>`, `<footer>`, `<nav>`, `<article>`, `<section>`, `<aside>`.
- Advanced form inputs: `date`, `number`, `range`, `color`.
- CSS Variables:
  - Declared in `:root` (`--primary-color`).
  - Used with `var(--primary-color)`.
- Accessibility basics:
  - `alt` attributes for images.
  - `aria-label` for buttons and interactive elements.
  - Keyboard navigation considerations.

---

## 🎯 How to Use This Repo
1. Open each `dayX.html` file in a browser to see the output.
2. Edit and experiment with the code to reinforce concepts.
3. Use `styles.css` to centralize styling and practice external CSS.
4. Review this README for quick revision before interviews.

---

## 💡 Interview-Style Questions
- Explain the CSS Box Model.
- Difference between inline, internal, and external CSS.
- Flexbox vs Grid – when to use each?
- Difference between relative, absolute, and fixed positioning.
- What are semantic HTML tags and why are they important?
- How do CSS variables help in theming?
- How do media queries enable responsive design?
