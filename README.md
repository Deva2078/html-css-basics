# html-css-basics

A beginner-friendly repository to learn and practice **HTML** and **CSS** fundamentals.  
This repo contains examples, explanations, and exercises to help you understand the building blocks of web development.

---

## 📖 What You'll Learn
- Basic HTML structure (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`)
- Common HTML tags (`<p>`, `<h1>`–`<h6>`, `<table>`, `<img>`, `<a>`)
- Text formatting tags (`<strong>`, `<em>`, `<mark>`, `<del>`, `<ins>`)
- Void elements (tags without closing, e.g., `<br>`, `<hr>`, `<img>`)
- Semantic vs non-semantic tags
- Introduction to CSS styling (inline, internal, external)
- How SEO-related tags improve accessibility and search ranking
